# 中断

`外部中断（EXTI）：`

​	Falling edge trigger detection ：when detected voltage  from High level to low level trigger the interruption

​	raising edge trigger detection ：when detected voltage from High level to low level trigger the interruption



The instance we press and depress the buttom, voltage jitter is severe

the built-in debounce capacitor is not enough to overcome this problem

so the 10ms delay for skipping the jitter period is significant



**Priority** : (The smaller the number, the higher the priority)

​	`Preemption Priority` :  first priority （抢占优先级）

​	`sub priority `: second priority（响应优先级）

​	this two priority share 4 bits, we can set how many bits is for Preemption and how many bits is for sub priority

	1. when 2 interruption come almost the same time, compare the Preemption priority first, then compare the sub priority
 	2.  when A interruption is working, a new interruption B comes, compare the Preemption priority, if same, B should wait for A to finish.

​	`HAL_Delay()` relay on the system tick timer, which provide 1ms timebase and has lower priority than the interruperted function, but we can change the priority value to make it proceed before others

寄存器操作多为位运算

**请求挂起寄存器**和**中断终端屏蔽器**同时为高电平时，中断控制器（NVIC）开始中断

`NVIC` : 嵌套向量中断控制器（Nested Vector Interrupted Controller）, controlling the function `EXTIx_IRQHandler()` 

其中EXTI5~EXTI9共享处理函数EXTI9_5_IRQHandler()

NVIC一直在检测EXITx中断处是否处于激活状态，会一直进行EXTIx_IRQHandler()，除非清除请求挂起寄存器中的对应位清除为0。 如：`HAL_GPIO_EXTI_IRQHandler(KEY1_Pin);`
